# 0003 — Greek/English UI with react-i18next, per-user language

**Status:** accepted (2026-11-15), phase 1 done · **Code:** `src/i18n/` (see its README:
conventions, Greek style guide, legal glossary), `backend-node/src/services/emailI18n.ts`,
`backend-node/src/lib/language.ts`

## Decision
- react-i18next, one JSON namespace per area in `src/i18n/locales/{en,el}/`; English is
  source + fallback.
- Language per user (`profiles.preferred_language`, `PATCH /api/v1/users/me/language`),
  install default `DEFAULT_LANGUAGE` / `VITE_DEFAULT_LANGUAGE` (`install.sh --language`,
  `kourtictl language`).
- Emails pick the recipient's language server-side; AI chat follows `Accept-Language`.
- Dates through `src/i18n/dates.ts` (date-fns `el` / `enGB`): English UI is now 24h,
  day-month order.
